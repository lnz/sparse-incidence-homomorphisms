\begin{homepagewidth}
There is a universal constant $C>0$ such that every finite hypergraph $H$
with $\adw(H)\ge2$ satisfies
\[
  \fhw(H)\le C\lambda(H)\adw(H)\log_2\adw(H).
\]
When $\adw(H)<2$, $\fhw(H)\le C\lambda(H)$.
\end{homepagewidth}
