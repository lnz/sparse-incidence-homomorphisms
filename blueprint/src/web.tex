\begin{homepagewidth}
There is a universal constant $C>0$ such that every finite hypergraph $H$
with $\adw(H)\ge2$ satisfies
\[
 \begin{aligned}
  \fhw(H)&\le C\mu(H)\adw(H)\log_2\adw(H),\\
  \fhw(H)&\le C\max\{1,\log_2\alpha(H)\}\adw(H)\log_2\adw(H).
 \end{aligned}
\]
When $\adw(H)<2$, $\fhw(H)\le C\mu(H)$ and
$\fhw(H)\le C\max\{1,\log_2\alpha(H)\}$ with the same constant.
\end{homepagewidth}
