Definition 3.1 Fractional edge-cover cost
✓
#

Uses

  • Definition 2.1

Lean declarations

  • Paper.Hypergraph.Cover

  • Paper.Hypergraph.indicator
  • Paper.Hypergraph.setCoverCost

For a demand \(x\), a cover is a nonnegative edge vector \(y\) with \(\sum _{e\ni v}y_e\ge x(v)\) for every vertex. Its optimum cost is

\[ \rho _H^*(x)=\inf _y\sum _e y_e, \qquad \rho _H^*(X)=\rho _H^*(\mathbf1_X). \]

An edge-dominated modular weighting is a nonnegative vertex vector \(w\) with \(\sum _{v\in e}w_v\le 1\) on each hyperedge; write \(b_w(X)=\sum _{v\in X}w_v\).

Lemma 3.2 Cover duality
✓
#

Uses

  • Definition 3.1
  • Definition 3.1

Lean declarations

  • Paper.Hypergraph.cover_duality

For a unit demand \(x:V(H)\to [0,1]\) there is an edge-dominated modular \(w\) such that

\[ \rho _H^*(x)=\sum _v w_vx(v), \qquad \sum _v w'_vx(v)\le \rho _H^*(x) \quad \hbox{for every admissible }w'. \]
Proof ▶

Construct a supporting linear functional for the sublinear cover-cost functional. Its values on singleton vectors yield \(w\). Feasible covers give the reverse inequality by exchanging the two finite sums.

Lemma 3.3 Restriction preserves cover cost
✓
#

Uses

  • Definition 3.1
  • Definition 2.1

Lean declarations

  • Paper.Hypergraph.cover_restriction

If \(X\subseteq W\), then \(\rho _{H[W]}^*(X)=\rho _H^*(X)\).

Proof ▶

In the manuscript, aggregate weights on edges with equal nonempty intersections with \(W\), and lift a restricted cover by choosing one original edge for each restricted edge. For Lean’s labelled edges, retain surviving labels and extend the other weights by zero.

Definition 3.4 Tree decompositions and width parameters
✓

A tree decomposition is a finite nonempty tree with vertex-subset bags, covering every hyperedge and vertex, such that the bags containing any fixed vertex form a connected subtree. For a bag cost \(b\), set

\[ \operatorname {opt}_H(b)=\inf _D\max _{t\in D}b(B_t). \]

Then \(\mathsf{fhw}(H)=\operatorname {opt}_H(\rho _H^*)\) and \(\mathsf{adw}(H)=\sup _w\operatorname {opt}_H(b_w)\) over admissible modular weights. For \(\mathsf{subw}(H)\) take the supremum instead over normalized, monotone, submodular, edge-dominated set functions.

Lemma 3.5 Width hierarchy and heredity
✓
#

Uses

  • Definition 3.4
  • Lemma 3.3
  • Definition 3.1

Lean declarations

  • Paper.Hypergraph.width_hierarchy
  • Paper.Hypergraph.width_hereditary

One has \(\mathsf{adw}(H)\le \mathsf{subw}(H)\le \mathsf{fhw}(H)\), and \(\mathsf{adw}(H[W])\le \mathsf{adw}(H)\) and \(\mathsf{fhw}(H[W])\le \mathsf{fhw}(H)\).

Proof ▶

Modular functions are submodular. Supporting modular weights bound each submodular bag value by its fractional cover cost. Restricting decompositions and extending admissible weights gives heredity.

Lemma 3.6 Component reduction
✓
#

Uses

  • Definition 3.4
  • Definition 2.2
  • Lemma 3.5

Lean declarations

  • Paper.Hypergraph.component_reduction

Each of \(\mathsf{fhw}(H)\) and \(\mathsf{adw}(H)\) is the maximum of its values on \(H[K]\) for \(K\in \mathcal C(H)\), with value zero in the empty case.

Proof ▶

Join the disjoint component trees, retaining their bags and internal paths. A hyperedge lies in a single component. Heredity gives the reverse bounds; passing to infima avoids requiring optimal decompositions to be attained.
