Theorem 1.1
#

There is a universal constant \(C{\gt}0\) such that every finite hypergraph \(H\) with \(\mathsf{adw}(H)\ge 2\) satisfies

\[ \mathsf{fhw}(H)\le C\lambda (H)\mathsf{adw}(H)\log _2\mathsf{adw}(H). \]

When \(\mathsf{adw}(H){\lt}2\), \(\mathsf{fhw}(H)\le C\lambda (H)\).
